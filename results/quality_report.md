## snapshot_completeness

Share of metadata links present in a snapshot. A partial snapshot biases every per-link average and breaks congestion episodes (a missing link ends a run).

```json
{
  "snapshots": 25,
  "incomplete": []
}
```

## stale_snapshot

Share of links whose band changed since the previous snapshot. LTA refreshes speed bands every 5 minutes, so a snapshot taken 15-20 minutes later in which almost nothing changed is probably a cached or repeated response.

```json
{
  "pairs_compared": 24,
  "stale": [],
  "changed_share_range": [
    0.1869,
    0.4823
  ]
}
```

## cadence_gap

The sampler waits 15 minutes after each fetch, so snapshots should be about 15-22 minutes apart. Longer gaps mean the sampler was stopped; much shorter ones mean an extra fetch outside the loop.

```json
{
  "intervals": 24,
  "long_gaps": [
    {
      "from": "2026-09-26T23:01:00",
      "to": "2026-09-27T15:50:00",
      "minutes": 1009.0
    }
  ],
  "short_gaps": [
    {
      "from": "2026-09-26T19:28:00",
      "to": "2026-09-26T19:33:00",
      "minutes": 5.0
    }
  ],
  "regular_intervals": 22,
  "regular_minutes_min_median_max": [
    17.0,
    19.0,
    21.0
  ]
}
```

## unknown_link_ids

```json

}
```

## unknown_band_share

## sampler_log_consistency

sampler.log gets one line per fetch made by the sampler loop. A different count from the number of snapshot files means some files were fetched outside the loop or some fetches failed.

```json
{
  "log_fetch_lines": 35,
  "snapshot_files": 36,
  "row_counts_in_log": [
    143787
  ],
  "other_lines": [],
  "log_has_timestamps": false
}
```

## od_vs_tapin
